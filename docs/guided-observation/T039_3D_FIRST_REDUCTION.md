# T-039 全站 3D-first 收缩

## 证据与决定

2026-08-10，维护者以具备化学基础的真实使用者身份复核 NH₃ T-038 样板，确认基础信息可以准确取得，但详细讲解没有形成相对教师或网课的竞争力。两张运行时截图还显示：

- 360px 右栏比 Viewer 内容更长，导致左侧 Viewer 下方出现大面积空白；
- 从长讲解底部点击“回到自由探索”后，面板高度骤减，浏览器把原滚动位置夹到新页面底部；
- 维护者更希望产品提供清晰、美观、可旋转缩放和切换结构状态的 3D 模型，把进一步资料查找交给学生自己。

因此取消原定 T-039 朋友 / 同学 Alpha。该决定来自维护者产品判断，不表述为普通学生研究结论；自动化测试也不替代真实用户证据。

## 选定布局

采用概念方案 B：

1. 3D Viewer 全宽显示；
2. 操作工具栏紧邻 Viewer；
3. “结构信息”默认折叠，不持久化；
4. 普通分子只保留名称 / 分子式、空间构型、典型键角和模型边界；
5. NaCl 与拼装实验室保留必要动态反馈，但在后续阶段压缩为摘要 + 折叠详情。

概念效果图只用于方向讨论，不作为仓库资产提交。

## 删除 / 保留矩阵

| 范围 | 删除 / 收缩 | 必须保留 |
| --- | --- | --- |
| 普通分子 | 步骤、完成状态、聚焦、自动开关、长讲解、退出引导 | Viewer、旋转 / 缩放、键角、孤电子对、标签、自动旋转 |
| 极性 / 轨道 / 有机平面 | Panel 专用长文、事实列表、教学 / 考试提示 | 模式 ID、短标签、渲染参数、场景内标签 / 平面 / 角弧 |
| 晶体 | `CrystalTeaching` 正文、观察指南、误区、原因段落 | 晶胞几何、模式、空隙阶段、核心晶体事实 |
| NaCl 周期工作台 | 长教学解释 | N=1/2/3、边框、选择、六配位、幽灵、隔离、精简实时状态 |
| 拼装实验室 | 已知分子教学简介等长段落 | 添加 / 拔下 / 撤销 / 补氢、分子式、价态、命名、诊断 |
| 目录 | 课程式长简介 | 32 个模块、分组、路由、Exam 内容与 `visualFocus` |

## 分阶段交付

### T-039A：共享布局与普通分子

- 单列全宽骨架；
- 通用 `StructureInfoDisclosure`；
- 删除普通分子公开引导 UI、状态、类型、数据和测试；
- 23 份手写结构不再含 `lessonSteps` / `guidedObservation`；
- 五个普通分子继续进入真实 Viewer，手动显示开关保持独立；
- 普通分子 Viewer 使用窄屏 440–500px、桌面 520–640px 的响应式高度；Viewer 顶部对齐固定页头后，完整工具栏无需继续滚动即可操作。

### T-039B：专题展示 Viewer

- 覆盖极性、σ/π、成键基础、乙烯 / 苯 / 乙炔和有机共面；
- 保留渲染控制，删除 Panel 专用教学正文；
- 使用共享折叠信息显示身份、当前模式、关键几何值和模型边界。

### T-039C：晶体与 NaCl 周期工作台

- 将 `crystalTeaching.viewModes` / `voidStages` 迁移为只含 ID 和短标签的 `CrystalControls`；
- 保留 `CrystalInfo` 的结构类型、晶格、配位和晶胞计数；
- 压缩普通晶体与 NaCl 周期工作台状态，周期与配位算法不变。

### T-039D：拼装实验室、目录与全局清理

- 拼装信息改为动态摘要 + 折叠诊断；
- Modules / Paths 简介收缩，Exam 保持现状；
- 删除最终无消费者的教学字段；
- 在 macOS 集中人工审核全宽布局引起的 Darwin 快照变化。

## 数据与模型边界

- 普通分子：键角为典型值，模型用于观察空间关系；
- 晶体：显示比例为教学模型，真实尺度以权威结构资料为准；
- 轨道：电子云形状和重叠为定性示意；
- 拼装：键长、键角和构象不是量化计算结果。

## 阶段验收

每阶段使用独立 PR，前一阶段合并后下一阶段才从最新 `main` 开始。每阶段至少执行 lint、build、logic、对应 Viewer 家族的系统 Chrome 无截图行为测试、production、`git diff --check`，并审计工作树、lockfile、版本与生成文件。

T-039A 的普通分子布局另以 1280×720、1552×926、390×844 冻结 Viewer 高度、工具栏首屏边界、44px 触控尺寸与无横向溢出；不通过悬浮覆盖工具栏来换取可达性。

Windows 不更新 Darwin 快照。T-039D 完成后，在 macOS 对受全宽布局影响的快照集中人工审核，只更新确认合理的基线。

## 明确边界

- 不修改原子坐标、化学键、晶胞几何和计算算法；
- 不改变模块数量、分组、路由、场景标签、操作模式或 Exam 内容；
- 不引入答题、评分、账号、数据库、AI 聊天或新大型功能；
- T-038 的 SHA、日期、阶段决定和验收结果保持历史原貌；D-044 只调整后续方向。
