# Chem3D Learn v0.1.0-rc.1

Chem3D Learn 的首个公开发布候选版本。它已经完成当前发布范围的功能、化学依据与 macOS 视觉回归验证，但仍是 **prerelease**，不是正式稳定版。

## 在线体验

[打开 Chem3D Learn](https://a7m0sphere.github.io/chem3D-learn/)

## 本版本可以做什么

- 旋转、缩放并分步观察典型分子构型、晶体结构、化学键与有机立体结构。
- 学习 CH₄、NH₃、H₂O、CO₂、BF₃ 等结构的 VSEPR、键角、孤对电子与极性。
- 观察 NaCl、CsCl、CaF₂、BaTiO₃、ZnS、石墨、MOF-5、MXene、PBA 等课堂教学模型。
- 在有机分子 3D 拼装实验室中拖拽原子和常用片段，并获得范围明确的实时反馈。
- 通过学习路径、考试专题和简洁中文讲解用于自学或课堂投影。

## 重点功能：Crystal Workspace

NaCl Crystal Workspace 可以在 1×1×1、2×2×2、3×3×3 周期模型之间切换，并显示外边框、全部晶胞边框或隐藏边框。选择一个具体离子显示副本后，可以观察它的 6 个异号最近邻、第一配位层和为补齐周期边界而显示的镜像，也可以隔离该配位环境。

界面明确区分有限超晶胞中的 canonical 位点、边界显示副本与临时周期补齐镜像。配位虚线只表达最近邻关系，不代表共价键。NaCl 岩盐型结构、常规胞坐标、组成、双方六配位和 `a/2` 最近邻关系已经依据 IUCr、AFLOW、Materials Project 等来源复核。

## 适合谁使用

- 希望建立分子和晶体空间直觉的中国高中生。
- 需要课堂投影、旋转模型和分步讲解的化学教师。
- 愿意体验并反馈浏览器兼容、教学表述与交互问题的项目使用者。

当前模型服务于高中教学表达，不代表科研级模拟或完整结构数据库。

## 已知限制

- 本版本是 `v0.1.0-rc.1` prerelease，不是稳定版；只有候选版本验证和试用反馈通过后才会考虑正式版本。
- WebGL 空间离子主要依靠 pointer 选择；工具栏和选择结果已提供键盘与辅助技术支持。
- GitHub Pages 深层 URL 的首个 HTTP 响应可能为 404，随后由浏览器中的 SPA fallback 恢复。
- 按需加载的 `ThreeViewerFrame` 仍有 Vite large chunk 非阻断警告。
- 前端主产品与可选只读后端尚未统一结构数据真源，线上主体验目前不依赖后端。
- BF₃ 缺电子表述与 CaF₂ 晶胞参数仍有独立化学复核待办。
- 当前不提供账户、云保存、模型分享、真实能量计算或全部结构化学内容。
