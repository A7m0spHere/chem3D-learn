> 审计日期：2026-08-01
> 审计对象：`main@b634839`、正式 GitHub Pages、当前前端源码与治理文档。
> 目标：判断项目是否已经适合进入真实用户测评，并把“还没完善”拆成可执行任务。

## 结论

当前项目已经具备稳定的 3D 产品骨架，但还没有形成完整的“观察—判断—作答—反馈”学习闭环。现阶段更适合称为**内部 Alpha / 产品完备度阶段**，不应把广泛 RC 真实反馈当作主线。

维护者和少量朋友可以参与后续 Alpha 验收；人数不是当前阻塞项。公开占位内容和三处化学待核实项已经收口，当前前置条件只剩最小自测闭环。

## 已经完成的基础

- 首页、结构库、模块详情、参考顺序、能力扩展、About 和有机拼装路由均已上线。
- 结构库当前展示 32 个模块。源码核对确认，现有模块均由手写结构数据或专题 Viewer 分发；`ModulePlaceholderViewer` 只保留为防御性 fallback，当前公开模块没有落入该路径。

- `v0.1.0-rc.1` 已部署；自动化构建、逻辑测试、生产预取测试和 Darwin 视觉基线已有发布记录。

## 影响“产品已完善”判断的缺口

### P0：三处已知化学待核实项已收口

T-033 已于 2026-08-01 完成以下 3 处核验：

1. `frontend/src/data/mockMolecules.ts`：BF₃ 缺电子表述。
2. `frontend/src/data/manual/caf2.json`：约 5.46 Å 的晶胞参数。
3. `frontend/src/data/organicBuilderSeeds.ts`：苯乙烯类乙烯基与苯环近共面的共轭构象说明。

BF₃ 现区分中心 B 未满足八隅体、Lewis 酸与 B—F 成键高级边界；CaF₂ 现注明萤石型 `Fm-3m`、4:8 计数、8:4 配位、室温附近常压约 5.463 Å 及显示尺度边界；有机共面页现明确实际是 `C₁₁H₁₁N` 四取代苯理想化综合模型，固定 45° 不是最低能或唯一构象。完整来源、最终文案、代码与测试映射见 `docs/CHEMISTRY_VERIFICATION.md`。上述 3 处 `TODO-CHEM-VERIFY` 已清理；其余化学内容仍按增量核验原则维护。

### P1：能力扩展仍是静态讲义，不是完整学习闭环

线上检查了 6 个专题详情：晶胞均摊、配位数、分数坐标、晶胞密度、空隙、金刚石与单晶硅。页面均包含知识说明、解题步骤、误区、自查提示和关联 3D 模块，但没有作答控件、即时判断、错误解释或重试入口。

因此学生可以“看懂说明”，却无法在站内验证自己是否真的会做。下一阶段应先做一个可复用的轻量自测组件，以一个核心专题为样板，再扩展到其余专题；不建设大题库、不引入账号或数据库。

### P1：公开目录的建设中内容已收口

T-034 已于 2026-08-02 从公开 `examTopics` 数据移除“XeO 特殊晶体结构”占位。能力扩展页现有 16 个专题均为已开放状态并提供可进入链接，分组数量为 5 / 4 / 7。

数据契约与页面行为测试会阻止无 route、`planned`、XeO 文案或“建设中”按钮重新进入公开目录。XeO 规划仍可保留在治理历史中，但不作为已交付产品展示。

### P2：真实反馈目标与当前阶段不匹配

T-031 的反馈入口和分诊机制仍然有价值，但当前没有足够产品完成度，也没有大规模试用者来源。现阶段应把它暂停为后续 Alpha 验收工具：由维护者和少量朋友走代表性路径、记录真实问题即可，不设置人数 KPI，也不据此宣称稳定版已经通过。

## 小范围 Alpha 的最低门槛

- 上述 3 个化学待核实项已经收口。
- 公开页面没有“建设中但不可进入”的卡片。
- 至少一个考试核心专题形成完整自测闭环，并通过逻辑与浏览器行为测试。
- 前端 build、lint、logic、production 回归通过。
- Windows 不更新 Darwin 快照；涉及可见 UI 的改动在后续 macOS 审核。

## 明确不纳入本阶段

- 登录、账号、云端学习进度或排行榜。
- 数据库、教师后台、支付。
- 大型题库或自动组卷。
- AI 聊天、Gemini API、动态 SMILES、RDKit runtime。
- 为了“看起来完整”继续堆叠竞赛材料和冷门晶体模型。
