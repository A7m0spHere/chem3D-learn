## 3. 误报排除记录（第一轮扫描 31 组异常的复核结果）

第一轮采用「同页连续缩放 6 视口」的扫描序列并报告 31 组异常；经新鲜加载对照复测 + 目检，确认其中绝大多数为**两类扫描假象**，避免 Phase 2 重复排查：

1. **不可见交互层**：`AtomPullHandle`（有机拼装手柄）等无文本/透明的 `<Html>` 层参与几何计算——有机共面系列（乙烯/乙炔/苯/共面综合）的「大量出界 + 叠印」实为此类，默认模式画布目检无任何可见标签。
2. **缩放序列时序假象**：连续缩放后测量位置滞后一拍——离子键 / 乙烯 / 有机共面在 1280 档的「下出界」新鲜加载复测**全部干净**。

被推翻的页级报告：ZnS 多晶型（LayerBadge/FocusLabel）、离子键形成、配位键形成、苯、有机共面系列——新鲜加载 6 视口全净。这些页面的真实风险在**交互模式**（键角 / π 键 / 拼装），Phase 1 仅扫默认模式，交互模式矩阵随 Phase 2 逐体系审计补齐。

## 4. 方法学沉淀（Phase 2 / Phase 3 复用）

- **每视口独立新鲜加载**（goto → fonts.ready → 稳定等待 → 扫描），不要在单页内连续缩放复用会话；
- 扫描必须过滤 `display:none` / `visibility:hidden` / `opacity < 0.05` 与无文本交互层，否则拼装手柄层会淹没真实缺陷；
- `±2px` 级断言与几何测量统一等 `.motion-page-enter` 动画结束（D-049 惯例）——本轮 CI 连续两轮各挂一个裸测量断言（specialty rail 300.82、molecule-viewer stage 3.39px）即同族问题，已随 PR #10 全部扫尾；
- 压模 / 字号可读性无法 DOM 判定，需截图目检（本轮抽查未见新增压模）。
