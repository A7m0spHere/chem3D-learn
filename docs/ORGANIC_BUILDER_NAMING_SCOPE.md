# 有机拼装器本地命名规则范围

## 定位

本模块是面向高中教学的离线、确定性命名器，不是完整的 IUPAC 命名数据库。

命名入口必须先验证中性价态和连通性，并保持以下优先级：

1. 教学词典精确匹配；
2. 本地基础规则生成；
3. 超出可靠范围时返回具体原因，不按分子式猜名称。

所有生成结果均提供中文名和英文名。当前图模型没有 E/Z、R/S 信息，因此不生成立体描述符。

## 已完成的规则

### 无环母体

| 项目 | 覆盖范围 |
| --- | --- |
| 母体长度 | C1–C10 |
| 碳骨架 | 直链和带直链 C1–C4 简单烷基支链的无环结构 |
| 不饱和键 | 烷、烯、炔、多烯、多炔和烯炔组合 |
| 前缀 | F、Cl、Br、I 和简单烷基 |
| 主官能团 | 羧酸、酰胺、醛、酮、醇、伯胺 |
| 优先级 | 羧酸 > 酰胺 > 醛 > 酮 > 醇 > 胺 |
| 多官能团 | 同类二醇、二酮、二胺、二酸等倍数后缀；低优先级官能团转为前缀 |
| 醚 | 两侧为简单直链烷基的醚，烷氧基限 C1–C4 |
| 骨架替代 | C1–C10 无环单路径中的 aza/oxa 替代命名 |

### 无环酰胺

| 项目 | 覆盖范围 |
| --- | --- |
| 酰胺母体 | 一个 C1–C10 无环酰胺基；母体可使用现有简单支链、烯和炔规则 |
| 氮取代 | 伯、仲、叔酰胺；最多两个 N-取代基 |
| N-取代基 | C1–C10 无环直链碳氢基团，可含双键或三键，必须从直链端点连接氮 |
| 位次与排序 | 使用 `N-`、`N,N-` 位次；与其他前缀一起按英文名称字母序排列 |
| 几何提示 | 酰胺氮按羰基共轭识别为近似平面 `sp²`，显示教学值 `≈120°` |

当前课堂草稿 `CH₂=CH–C≡C–NH–C(=O)–C≡C–CH₃` 生成：

- `N-(丁-3-烯-1-炔-1-基)丁-2-炔酰胺`
- `N-(but-3-en-1-yn-1-yl)but-2-ynamide`

母体选择、编号和取代基排序不依赖原子 ID、添加顺序或数组顺序。

### 环烷烃

| 项目 | 覆盖范围 |
| --- | --- |
| 母环 | C3–C10 饱和单环 |
| 取代基 | 卤素、直链 C1–C4 烷基；烷基不得长于母环 |
| 取代数 | 支持最多十个简单取代基，包括偕二取代 |
| 编号 | 最低位次组；仍相同时按英文取代基名称字母序确定较低位次 |

### 苯环

苯环必须以交替单双键教学图表示。已收录的苯仍由教学词典优先识别。

| 项目 | 覆盖范围 |
| --- | --- |
| 取代基 | 卤素、直链 C1–C4 烷基、羟基、氨基、直链 C1–C4 烷氧基、醛基、羧基 |
| 取代数 | 1–6 个受支持取代基 |
| 编号 | 主官能团优先，其次最低位次组，再以英文前缀字母序打破平局 |
| 二取代教学名 | 1,2- = 邻位 / ortho；1,3- = 间位 / meta；1,4- = 对位 / para |
| 多主官能团 | 二至六个同类羟基、氨基、醛基或羧基使用倍数后缀 |

数字编号名是主显示名称；邻、间、对位名称只作为二取代苯的教学别名。

## 明确不支持

以下结构必须返回 `unsupported` 和具体中文原因，不生成猜测名称：

- C11 及以上母体；
- 环烯烃、环炔烃、芳香稠环、桥环、螺环和杂环；
- 苯环或环烷烃上的复杂支链、跨接取代基；
- 普通仲胺、叔胺、酰卤、酯、酸酐及其他未收录的羰基衍生物；
- 多酰胺、酰亚胺、环酰胺、苯甲酰胺，以及含支链、环或杂原子的 N-取代基；
- 超出当前简单规则的杂原子桥和复杂多官能团；

未完成价态或含多个独立片段的结构返回 `not-ready`，不进入系统命名。

对于可能存在 E/Z、R/S 或其他立体异构的连接结构，当前只生成不含立体描述符的基础名称，并在结果卡中明确说明这一限制。

## 验收证据

- `frontend/tests/logic/organic-builder.logic.spec.ts` 覆盖母体、官能团优先级、不饱和键、环烷烃、苯环、顺序稳定性和超范围原因。
- `frontend/tests/visual/organic-builder.visual.spec.ts` 从真实拼装交互验证氯甲烷，以及苯到氯苯、邻二氯苯和三氯苯的实时名称变化。
- 前端变更完成后必须通过 `npm run test:logic`、有机拼装器 Playwright 测试、`npm run build`、`npm run lint` 和 `git diff --check`。
